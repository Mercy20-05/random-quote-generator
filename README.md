# Random Quote Generator

## Project Overview

The Random Quote Generator is a simple and responsive web application
developed using HTML5, CSS3 and JavaScript.

The application displays a random quote along with the name of its
author whenever the user clicks the "New Quote" button.

The project was developed according to the Web Development Track
requirements.

---

## Description

The application provides an interactive way to display motivational
and inspirational quotes.

Users can:

- View a quote and its author.
- Generate a new random quote.
- Share the displayed quote.
- Copy the quote when the browser does not support the Web Share API.
